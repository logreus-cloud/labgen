# Введение

Заголовки «Введение», «Заключение» и «Список использованных источников» не нумеруются —
список таких заголовков задаётся в `labgen.yaml`. Все остальные разделы labgen нумерует сам:
первый уровень даёт «1», «2», вложенные — «1.1», «1.2.3».

Цель работы — показать, как из обычного Markdown получается отчёт, оформленный по ГОСТ 7.32-2017:
шрифт Times New Roman 14 пт, полуторный интервал, абзацный отступ 1,25 см, выравнивание по ширине.

# Теоретическая часть

## Основные понятия

Обычный текст пишется как обычно. Доступны **полужирный**, *курсив* и `моноширинный` фрагменты,
а также перечисления:

- первый пункт;
- второй пункт;
    - вложенный пункт;
- третий пункт.

Нумерованные перечисления тоже работают:

1. подготовить данные;
2. выполнить запрос;
3. проверить результат.

## Иллюстрации

Картинка на отдельной строке превращается в рисунок с подписью по центру.
Текст в квадратных скобках становится подписью, нумерация — сквозная и автоматическая.

# Практическая часть

## Листинги

Строку `Листинг: ...` перед блоком кода labgen превращает в подпись с номером.

Листинг: Подключение к базе данных

```python
from pymongo import MongoClient

client = MongoClient("mongodb://localhost:27017")
database = client["lib_userov"]
print(database.list_collection_names())
```

Подпись можно задать и в информационной строке блока — `python caption="Пример"`.
Блок без подписи просто вставляется моноширинным шрифтом и не занимает номер.

## Таблицы

Строка `Таблица: ...` перед таблицей даёт подпись слева над ней.

Таблица: Результаты замеров времени выполнения
